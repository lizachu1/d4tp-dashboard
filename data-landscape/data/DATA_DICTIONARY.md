# Data dictionary: California cradle-to-career data landscape

Research current as of November 14, 2026. All files are generated by `scripts/build_data.py`, which is the single place to edit. Run `python3 data-landscape/scripts/build_data.py` after any change.

## Files

| File | One row per | Use it for |
|---|---|---|
| `sources.csv` / `sources.json` | Data source (60) | The catalog: who owns what, who is in it, what it holds, how it links |
| `linkages.csv` / `linkages.json` | Source-to-source link (84) | The network: which systems exchange or match records, and which links are missing |
| `identifiers.csv` / `identifiers.json` | Person identifier (18) | Which ID covers which ages, and where the chain of IDs breaks |
| `gaps.csv` / `gaps.json` | Linkage gap (13) | Narrative gap analysis with evidence |
| `heatmap.json` | Handoff between segments (13) | Gap scores by dimension, 0 (strong) to 4 (critical) |
| `recommendations.csv` / `recommendations.json` | Recommendation (15) | The 10+ year strategy, grouped in three phases |
| `timeline.json` | Milestone (20) | History from 2019 to now |
| `data.js` | Everything above | Loaded by the dashboard (`../index.html`) |

## heatmap

`dimensions` lists the seven columns. Each row in `rows` is a handoff (for example "Early care to TK and kindergarten") with `scores` in the same order as `dimensions` and a short `why`.

| Score | Meaning |
|---|---|
| 0 | Strong: routine, individual-level, in C2C |
| 1 | Working with minor gaps |
| 2 | Partial: some data or some populations |
| 3 | Weak: mostly aggregate, voluntary, or blocked |
| 4 | Critical: no data path today |

Scores are analyst judgments based on the sources and linkages in this database. They are meant to start a conversation with agencies, not to grade them.

## gaps and recommendations

Gaps carry a `type` (`identifier`, `coverage`, `governance`, `content`, `standards`, `capacity`, `access`), a `severity` from 1 to 5, the evidence we relied on, and the recommendations that address them. Recommendations carry a `horizon` (three phases from 2027 to 2037), the policy `vehicle`, the bodies that can act, the D4TP 2027-2028 priority they support (`P1` Early Learning, `P2` TK-12, `P3` Higher Education, `P4` Workforce Pathways, `P5` Statewide Infrastructure), and a success `metric`.

## Known limits

- Public pages on c2c.ca.gov and leginfo were not directly readable from the research environment, so C2C partner details come from search excerpts of board materials, news releases and press coverage. Entries marked `needs_verification` should be checked against the 2026 C2C Governance Manual and Data Elements by Provider list.
- Population counts are rounded and meant for orientation.
- Key variables are the policy-relevant highlights, not full file specifications.
